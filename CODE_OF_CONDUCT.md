# Code of conduct

Be kind and assume good intent. Critique code and ideas, not people.
Harassment, personal attacks, and publishing anyone's private information,
including landlords' and other renters', are not acceptable here.

The maintainers may edit or remove comments, issues and pull requests that do
not follow this, and may block people who keep doing it. Report a problem
privately to the maintainers through the contact on the GitHub profile of the
repository owner.

This text is adapted from the spirit of the Contributor Covenant, version 2.1.
