Local agent forLocal agent for renting in the Netherlands

It watches Dutch rental sites and aims to write to the landlord within a minute of a new listing that matches your search. It reads the replies and answers the routine ones. Anything that needs a person comes to you. It is free and runs on your own computer.

How it worksHow it works

From listing to message

  1. 01

    Watch

    It checks the search pages of every site you enable, every 90 seconds for the fast ones, and notes anything it has not seen. The sites' own alert emails are a second way in.

    poll 90 s ± 20%, alert emails
  2. 02

    Match

    Each listing is checked against your rent, size, area and move-in date. The same home on three sites counts once. Likely scams are never contacted.

    rent ≤ €1,200, Utrecht, from 1 Nov
  3. 03

    Write

    A match gets a message in Dutch or English with your details, through the best free channel: a contact form, a platform message or an email to the agent.

    form, message or email
  4. 04

    Sort

    Replies are read and sorted. Routine questions are answered from your profile, and viewings inside your free hours are booked. Money, contracts and ID go to you.

    Agent accessAgent access

    Ask Claude what is waiting

    The agent runs an MCP server. Add it to Claude Code or Claude Desktop and Claude can read your inbox, search listings, draft replies and change a search. Tools that contact a real person say so in their description, and withdrawing every application needs an explicit confirmation.

    The same actions are a REST API on 127.0.0.1 and a CLI where every command takes --json.

    PrivacyPrivacy

    Your computer, your data

    Listings, messages and documents stay on your disk.
    One SQLite file and a documents folder under ~/.local/share/nl-property-finder. Delete the folder and they are gone.
    Keys and passwords sit in one file only you can read.
    secrets.env is created with mode 0600, never written to a log and never returned by the API. Site logins are browser profiles on your disk.
    There is no telemetry.
    Nothing is sent to the author, and there is no server to send it to. By default the dashboard and the API listen on 127.0.0.1 only.
    What does leave your computer.
    Requests to the sites you enable, the messages it sends for you, mail through the mailbox you give it, address lookups at PDOK, push titles if you set up ntfy or Telegram, and listing text sent to Claude only if you turn that on.

    ContributeContribute

    Add a rental site in one file

    A site is one adapter: a typed module with recorded fixtures, or for an ordinary estate agent, a YAML file with a URL and a few selectors. Copy an existing one, record its fixtures and open a pull request. Tests never touch a live site.

    Run it on your computer

    Install

    git clone https://github.com/danieltyukov/nl-property-finder
cd nl-property-finder
npm ci
npm run nlpf -- init
npm run nlpf -- on

    init asks for your search and profile. on starts the agent as a background service that starts at login. To look around first with made-up listings and landlords, run npm run demo.
